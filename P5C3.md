### Configure Git with an SSH key

> :information_source: Most Git servers authenticate using SSH public keys (to learn more https://openclassrooms.com/fr/courses/43538-reprisez-le-controle-a-laide-de -linux/41773-the-secure-remote-connection-with-ssh ). You will need to create a new key if you do not have one. This process is similar in all operating systems.

> SSH is a protocol that allows us to connect to remote machines. To use it, you have to create an "identity" which is made up of two files, one public, the other private (the private one must be protected really well, it's a bit like your password).

> If SSH is not required for the use of Git, you will quickly be limited in your use without it, we have already, potentially, suffered a little bit to install Git. more.. Like that afterwards it's a long calm river.

#### Create your SSH key pair


First, let's check that you don't already have a key. By default, a user's SSH keys are stored in that user's ~/.ssh directory. You can easily check if you already have a key by going to this directory and listing the contents:

```console
ls -a ~/.ssh
-r-------- 1 oripekelman staff 3243 Jun 24 10:57 id_rsa
-rwxrwxrwx 1 oripekelman staff 741 Jun 24 10:57 id_rsa.pub
-rw-r--r-- 1 oripekelman staff 2410 Jun 24 10:57 config
-rw-r--r-- 1 oripekelman staff 11120 Oct 22 15:07 known_hosts
```


You are looking for a pair of files named id_dsa or id_rsa and a matching file with a .pub extension. The .pub file is your public key and the other file is your private key (you can note in our directory listing on the left a difference in the permissions of the .id_rsa files, my private key is read only.. and only for me. While the public key id_rsa.pub.. it has fully open rights. It is public.) .

If you don't have these files (or you don't even have a .ssh directory), you can create them by running a program called ssh-keygen, which comes with the SSH package on Linux/Mac systems and ships with Git for Windows:

```console
ssh-keygen -o
```

It first confirms where you want to save the key (`.ssh/id_rsa`): keep the default option. Then it asks twice for a passphrase, which you can leave blank if you don't want to enter a password when using the key.

You can also use the `ssh-agent` tool to avoid having to enter the password each time.

#### Configure the Git server with its SSH key

##### Github

Now that we are sure we have our key... just configure the Git server with it. For example with github.com you can on https://github.com/settings/keys click on "New SSH Key" then paste the contents of its file id_rsa.pub


> :warning: Never oh never. The private key, `id_rsa` should only leave your computer. It doesn't even back up a private key. That's fine, only the public key that needs to be sent.

##### Platform.sh
With platform.sh it's even easier once you have the `platform` command line tool installed just type:

```console
platform ssh-key:add
```
And they will take care of the rest.
