## Installing and configuring Git

### Install git

#### By downloading

As we said there are many ways to use Git (through the web, with a GUI, an IDE) but we will concentrate on its use at the command line, with the “official” version, you can find it here: https://git-scm.com/download/

> FRAME Command line
> If you are not comfortable with a terminal, I invite you to take a quick look at: https://openclassrooms.com/fr/courses/43538-reprenez-le-controle-a-laide-de -linux/38076-enter-a-command you will see we get a taste for it quickly.

#### Linux

To start, this will suffice. But be aware that each operating system has its preferred way of installing software so that updating it is simple. So on an Ubuntu or Debian-type Linux we prefer to type `sudo apt-get install git-all` on the command line on a Redhat derivative `sudo dnf install git-all`.

#### OS X

On Mac, two simple options the first is to install Xcode, the second is to use the package management system at the HomeBrew command line and type `brew install git`.


#### Windows
As for windows, we advise you either to follow the same method as for Mac, by installing Chocolatey then `choco install git` or (even better) we install the Windows Subsystem for Linux you can then fall back on your feet and follow the instructions for Ubuntu (so `sudo apt-get install git-all`). Indeed if Git exists for all common operating systems (Windows, Mac OS X, Linux) and it works the same way everywhere, on old Windows systems its use was very difficult (like most online tools commands that target Linux-like systems).

#### Test the correct installation:

On OS X if the installation did not go well it may offer you to install XCode. Done.


#### Configure Git
Now, and this is important, you have to tell Git who you are. As we indicated at the very beginning Git will allow us to follow who did what when and why. And for that he needs to know the "Who". Nothing could be simpler on the command line, we can put our name and email.

```console
  git config --global user.email "you@example.com"
  git config --global user.name "Your Name"
```

This information will end up in a Git config file in `~/.gitconfig`
